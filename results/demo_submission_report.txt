PATTERN RECOGNITION SYSTEM - DEMO APPLICATION REPORT
Course: CT104-3-M Pattern Recognition
Task Reference: 2.1.1
Date: 14-Mar-2026

1) APPLICATION SUMMARY
A local MATLAB demo application was implemented to classify uploaded handwritten digit images
without re-running the end-to-end training pipeline.

Implemented files:
- src/demo_app.m
- src/demo_predict_digit.m
- src/prepare_demo_assets.m

Demo capabilities:
- User uploads image files (.png, .jpg, .jpeg, .bmp, .gif, .tif, .tiff)
- Image is preprocessed into MNIST-like 28x28 format
- Predictions are produced by all 3 trained models:
  * SVM (HOG features)
  * Random Forest (HOG + LBP + Statistical features)
  * k-NN (Raw pixel features)
- Confidence score is shown for each model

2) PERFORMANCE ANALYSIS (TEST SET)
Based on results/evaluation_log.txt:

SVM:
- Accuracy: 98.16%
- Precision (avg): 98.18%
- Recall (avg): 98.17%
- F1-score (avg): 98.16%
- Inference time on 10,000 samples: 137.41 s

Random Forest:
- Accuracy: 98.15%
- Precision (avg): 98.15%
- Recall (avg): 98.13%
- F1-score (avg): 98.14%
- Inference time on 10,000 samples: 6.84 s

k-NN:
- Accuracy: 96.73%
- Precision (avg): 96.79%
- Recall (avg): 96.69%
- F1-score (avg): 96.72%
- Inference time on 10,000 samples: 191.48 s

Observations:
- SVM and Random Forest provide near-identical top accuracy.
- Random Forest is significantly faster at inference than SVM and k-NN.
- k-NN is simple and interpretable but comparatively slower and less accurate.

Deployment recommendation:
- Best accuracy: SVM
- Best speed-accuracy balance for demo responsiveness: Random Forest

6) LIMITATIONS AND NOTES
